# Product Context

## Why this project exists
This project is a Universal Commerce Platform - Catalog Service designed to provide a flexible and scalable solution for managing products across different channels and platforms for e-commerce, marketplace, or physical platforms. It aims to solve the challenges of managing diverse product catalogs in a unified way.

## What problems it solves
- **Multi-Channel Management**: Enables managing products across different sales channels (e-commerce, marketplace, physical stores)
- **Multi-Platform Support**: Supports different platforms like mobile apps, web, and kiosks
- **Flexible Feature System**: Provides a dynamic attribute system for products with validation
- **Merchant & Store Management**: Supports multiple merchants and stores
- **Category-Specific Validation**: Enforces different validation rules based on product categories

## How it should work
The system should allow:
1. Creating and managing products with category-specific attributes
2. Validating product features based on category-specific rules
3. Searching and filtering products based on various criteria
4. Managing product availability across different channels and platforms
5. Supporting different merchants and sellers

The validation framework should dynamically apply appropriate validation rules based on product category, ensuring that products meet the specific requirements of their categories.
